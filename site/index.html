NetHack is the deepest game ever made. Its UI is from 1987.

NetHack is a dungeon crawler from 1987 that people still play today because no other game matches its depth: every object has behaviors, every monster has a personality, every death teaches you something. It is famously, brutally, wonderfully hard.

It is also famously played through a terminal window full of ASCII characters — @ is you, d is a dog, and that is the entire graphics budget. The game underneath deserves better, but every attempt to modernize it has meant forking the game itself, and forks drift, rot, and die.

So we did what Neovim did to Vim.

We cut the game in two: the engine (all of NetHack's brain, zero display code, zero disk code) and the interface (anything that can speak JSON). The world exposes everything as a documented API — deeds in, perceptions out (full reference). Anyone can build a client — 3D, mobile, voice-controlled, whatever — without touching the game.
