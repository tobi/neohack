What is neonethack

neonethack is NetHack with its head removed — respectfully. The unmodified game core (dungeon generation, monsters, RNG, rules, saves) runs as a headless engine behind a new window port that speaks newline-delimited JSON-RPC 2.0 on stdio instead of drawing to a terminal.

The three rules

  1. All of the brain is in the engine. No game rules in any client, ever. If your client computes something the engine should know, that is a bug in your client.
  2. Zero terminal leaks out of the world. No glyphs, no map cells, no menus, no keystrokes on the wire — only deeds in and perceptions out. NetHack's input choreography happens privately inside the core; clients see named actions, typed decisions, and events.
  3. Everything is replayable. The protocol stream plus the starting seed fully determines a session. Rerun the log and you are back at the same spot, byte for byte; from there, play continues live.

The pieces in this repo

lib/            libneonethack: the world, in C (actions, decisions, perception)
cli/            nhxcli: the reference bridge binding (JSON lines)
mcp/            MCP proxy + webmcp: the world for agents and the web
client/         reference Three.js client (the existence proof)
bun_server/     this site + the world API at /mcp + API docs at /api-docs
upstream/       the unmodified NetHack core + headless engine port beneath
