Your strategy starts here.

main.ts exports defineBot({ name: "My bot", autoloot: { … }, initialize({ hero, game, log }) { … } }). Initialize once, register observation listeners, and await actions in one turn listener.

Use relative imports between up to 20 JS/TS files. Autocomplete, hover documentation, and type diagnostics use TypeScript across your files. Press Ctrl+Space for suggestions. Tests have no network or npm access.

import { defineBot, direction } from 'neonethack';

export default defineBot({
  name: "My bot",
  autoloot: { enabled: true, itemTypes: ["gold", "food"], arrows: false, leaveCorpses: true, leaveKnownCursed: true, lootPatterns: ["ration"], ignorePatterns: ["corpse"] },
  initialize({ hero, log }) {
    hero.addEventListener('enterLevel', ({ detail }) =>
      log('Entered', detail.to.depthLabel));
    hero.addEventListener('turn', async () => {
      if (hero.decision) { hero.stop(); return; }
      await hero.go(direction.northWest);
    });
  },
});

The imp starter keeps its preferences in strategy.ts. Observation events include mapChange, entitySeen, itemSeen, inventoryChange, vitalsChange, decision and end. Notifications are read-only; turn coordinates input. No action means an idle stop.

hero.go(entity) attempts one step toward a visible creature. Sense again after every action. entities.Balrog selects a perceived species; entities.Enemy selects known hostiles. Hunger may be unknown. Inspect action outcomes and handle decisions explicitly.

Script state starts as "run"; read the game through hero.snapshot. Any callback can return a state name or {state: {...}}. Return null to yield: no further script events fire. Listen to stateChange for from, to and deny(); player overrides bypass vetoes. Use hero.controls.button({id, label, onClick}) and hero.controls.checkbox({id, label, checked, onChange}) to expose controls. log(...) and hero.journal.log(...) produce clearly marked script notes.

With construction autoloot.review: true, beforeLoot can explicitly select or cancel a real pickup choice before transfer. itemLooted reports confirmed acquisition and containerOpened reports disclosed contents. Cancel a standing decision before dropping an item.

Each test gets a fresh game. Random class and seed are selected once per run; their actual values appear above the world. Tests stop after 1,000 API calls or five minutes.
