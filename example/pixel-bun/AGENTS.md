# Pixel client

Read [DESIGN.md](DESIGN.md) before visual or interaction changes, and maintain it
as the user's choices develop. This example is a client of the public library API;
all repository boundary, storage, licensing and verification rules still apply.

Keep only the finished-project PNG exports listed in `art/recipe.json`. Never
copy raw skill templates, pixel grids, full vendor sheets, catalogs or private
tools into source. Preserve the exact art terms and run `tests/assets.test.mjs`
when changing this selection; a smaller export is not redistribution permission.
